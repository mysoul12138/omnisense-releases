# OmniSense（万象手柄）

> English version: [README.en.md](README.en.md)

面向 Windows 的 **DualSense / DualShock 4 增强软件**：把自适应扳机、遥测特效、配置档案、虚拟手柄与设备隐藏，整合进一个干净、克制的桌面应用。免费下载使用（闭源），本仓库为官方**下载与自动更新通道**。

## 它能做什么

- **自适应扳机工作台** — 12 种固件级扳机效果（反馈阻力、武器、弓、机炮、多段位置……），左右扳机独立编辑，快速预设、镜像、一键释放；效果持久保存，手柄重新连接自动恢复。
- **赛车遥测特效** — 接收《极限竞速》系列的官方数据输出（Data Out），用实时遥测驱动扳机阻力、油门重量感、漂移脉冲、灯条与震动；无需任何第三方 mod，游戏里开启数据输出即可。
- **多游戏遥测** — 内置《英雄联盟》Live Client 适配器：自动读取对局数据，把击杀等事件变成手柄反馈，无需游戏内设置；本地桥接（HTTP）还可把任意游戏的自定义遥测数据接进来。
- **游戏原生震动共存** — 虚拟手柄回传游戏原生震动，与遥测 / 触觉效果按马达逐路混流，互不打架。
- **灯条与音频直通** — 灯光颜色随心设置；把系统音频直通到手柄扬声器与触觉通道（USB 连接）。
- **配置档案** — 一个游戏一套配置：灯条、扳机、按键映射、mod、震动全部按档案走；绑定程序后自动切换档案。
- **按键映射** — 每个手柄键都可重排为其它手柄键，或直接映射成键盘 / 鼠标按键（替换式：映射后该键不再输出手柄信号；无宏）。
- **触控板 → 鼠标** — 把 DualSense 触控板当鼠标用：单指点按（含拖拽）、双指滚动，随时开关。
- **虚拟手柄** — 为不支持 DualSense 的游戏提供 X360 / DS4 两种虚拟形态，热切换。
- **设备守护** — 一键用 HidHide 屏蔽物理手柄（其它程序看不见，只有 OmniSense 能用），彻底解决"一个手柄多个程序抢"；检测到 DualSenseY 在运行时自动让位共存。
- **MOD 指令通道** — 直接接收社区 DSX 生态发往本地 6969 端口的指令 mod（mod 侧零配置）；自家 manifest mod 另提供可视化配置卡片。
- **中英双语界面** · **应用内自动更新** — 无需手动更新器，新版本在应用里一键升级。

| **OmniSense_<版本>_x64-setup.exe** | **安装版（推荐）**：开始菜单 / 托盘、自动更新、标准卸载 |

首次运行时，应用内的**驱动向导**会自动检测运行所需的两个开源驱动（ViGEmBus、HidHide）并引导安装——安装驱动需要管理员授权（UAC），应用本体日常运行**不需要**管理员权限。

> 系统要求：Windows 10 / 11 x64；支持 DualSense 与 DualShock 4（USB 或蓝牙）。

## 签名与安全

- 更新全程加密校验：清单签名 + 安装包哈希，任一不符即拒绝。
- 安装包未做商业代码签名，Windows SmartScreen 首次运行可能提示"未知发布者"——确认文件来自本仓库 Releases 后选择"仍要运行"即可。
- 内置的第三方组件与驱动许可详见每次发布随附的 **NOTICE.md**。
- 配置与数据全部保存在本机（%APPDATA%\\OmniSense）；除检查更新外，应用不主动发起外网连接。

## 常见问题

- **手柄连上没反应？** 打开应用 → 设置页，看一下驱动状态卡：虚拟手柄与设备守护依赖 ViGEmBus / HidHide 两个驱动，未安装时按提示一键安装。
- **和 DualSenseY 一起用会冲突吗？** 不需要手动处理——检测到 DualSenseY 运行时 OmniSense 会自动暂停对手柄的输出（该保护默认开启、可关）。
- **怎么彻底卸载？** 设置 → 应用 → OmniSense → 卸载（或安装目录下的 uninstall.exe）；配置文件在 %APPDATA%\\OmniSense，删除即彻底清空。
